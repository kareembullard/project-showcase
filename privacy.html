Privacy & Terms

Last updated: July 2026

This page covers every app in this showcase (the project portfolio hub and the nine apps linked from it). It's written in plain language on purpose — there's no account system, no data collection, and nothing complicated going on.

The short version: nothing you do in these apps is sent anywhere. Everything is stored only in your own browser and disappears if you clear your browser data.

What this site is

This is a personal portfolio by Kareem Bullard, showcasing a set of self-contained web app demos — dashboards, planners, and tools built to demonstrate product and front-end engineering work. None of these apps are commercial products, and none are intended for real business, financial, legal, medical, or property decisions.

Data & privacy

There are no accounts, no sign-ups, and no server behind these apps. Anything you type, add, edit, or upload — a project, a property, a story, a document — is saved using your browser's built-in localStorage, scoped separately to each app.

  • Data stays on your device. It is never transmitted to Kareem Bullard, this domain, or any third party.
  • Clearing your browser's site data (or using a different browser or device) removes it completely and permanently.
  • Each app's data is independent — there is no shared account or profile linking them together.

No tracking, no cookies

These apps run no analytics, no advertising, no cookies, and no fingerprinting scripts. Nothing about how you use them is recorded or observed.

Third-party resources

To render properly, these pages load a small number of third-party resources at page-load time:

  • Google Fonts (Inter, Space Grotesk, JetBrains Mono) — for typography
  • Lucide and Font Awesome icon libraries, served via CDN
  • Chart.js, served via CDN — for the charts and graphs

Loading these involves your browser making a normal request to those providers' servers — the same as any website using CDN-hosted fonts or libraries — which may log standard request metadata (such as your IP address) under their own privacy policies. No data from within these apps is sent to them.

Demo & sample data

All data shown by default — projects, tenants, budgets, tasks, articles, and so on — is fictional sample data created for demonstration purposes. Anything you add yourself is your own test data. None of it reflects real people, companies, or finances, and none of these tools should be relied on for real-world decisions.

Terms of use

These apps are provided "as is," for demonstration and portfolio purposes, with no warranty of any kind. You're welcome to explore, test, and interact with them freely — just don't use them as a substitute for real financial, legal, medical, or property-management software.
